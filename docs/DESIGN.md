## CSS Libraries

I have been using Bootstrap before very much as it was my first CSS library. But then I have tried others like Bulma,
UIkit and a few others. The past year I have been using Tailwind CSS. And I am still in process of learning it.
Normally I dislike to have much CSS in components with Tailwind (can look messy) and I did strive to develop 
my own CSS library in pure CSS.

I have in at least two previous project used Shadcn UI, and I am very impressed with it. Shadcn UI is an 
Open-code collection of reusable UI components. It is based on Tailwind CSS, Base UI (unstyled components).
You can choose to use components from Shadcn UI and then use that as base code for creating your own components.
With Shadcn UI you can also generate startup code for your styling (index.css) with which preferable colors, fonts, 
icons and more.
It even have built-in CSS code for light and dark mode when you generate this Shadcn UI.  
https://ui.shadcn.com/
https://tailwindcss.com/
