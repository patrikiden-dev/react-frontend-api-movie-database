## Learning

This is where I had the most help from. I use this to teach me things. And I usually type in a simple prompt like:
`I want to learn about React Router 8 and explain for me step by steps`.

What I have learned by many mistake are that you should always write in the version of that Tool och Program you want to learn so you do not get some old instructions.

When it is something har to understand and need a deep dive. I could just startup a side project just to try coding and test without using the project.

It is also good to not ask for too complex things first. Split up something you want to know and learn in smaller parts.
If you ask about too complex things at once, you might get a long answer and you end up not learning anything.

## Prompting

### Versions

What I have learned is that it is very important to write as detail you can when you asking for good information.
Always add version when you're asking about a library och language. Like I want to learn about React Router 8.

### Boundaries

Tell AI about you boundaries and be specific in details.


### Context dilution

When you having a discussion with AI and the chat history get large. It can be slow.
Instead, you can ask for a summary of the chat and then you copy that into a new Chat.
Some AI have a button for that.
